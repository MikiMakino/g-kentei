# 人工知能分野の問題

AI研究では、単に「計算機が賢く振る舞う」だけではなく、理解、意味、身体、常識をどう扱うかが長く議論されてきた。

## トイプロブレム

**トイプロブレム**とは、単純化された閉じた世界の問題のこと。

| 代表例 | 内容 |
|--------|------|
| 迷路 | 探索によりゴールまでの経路を見つける |
| ハノイの塔 | 手順探索により目的状態へ移す |
| 三目並べ | ゲーム木探索で最適手を考える |
| 定理証明 | 論理規則により証明を進める |

第1次AIブームでは、探索・推論・記号処理によりトイプロブレムで成果が出た。しかし、現実世界の問題は条件が複雑で曖昧なため、同じ方法をそのまま一般化することは難しかった。

!!! note "試験ポイント"
    トイプロブレムでの成功は、初期AIの有効性を示した一方、現実問題への限界も示した。

## フレーム問題

**フレーム問題**とは、行動後に「何が変わり、何が変わらないか」をすべて記述することが難しい問題。

例：ロボットが机の上のコップを持ち上げる場合

| 変わること | 変わらないこと |
|------------|----------------|
| ロボットの手の位置 | 机の色 |
| コップの位置 | 部屋の壁 |
| コップを持っている状態 | 時計の位置 |

現実世界では、行動と無関係な不変条件が膨大にある。すべてを明示的に列挙しようとすると知識表現が複雑になる。

!!! note "試験ポイント"
    フレーム問題は、常識推論や知識表現の重要課題として押さえる。

## チューリングテスト

**チューリングテスト**は、アラン・チューリングが1950年に提案した、機械が人間らしい知的応答を示せるかを評価する考え方。

- 判定者がテキストによる対話を行う
- 相手が人間か機械か区別できなければ、機械は知的であるとみなす
- 論文「Computing Machinery and Intelligence」で提案された

ただし、会話が自然に見えることと、本当に意味を理解していることは同じではない。この限界は、中国語の部屋などの議論につながる。

## 強いAIと弱いAI

| 種類 | 説明 | 現状 |
|------|------|------|
| 弱いAI | 人間の知的作業を模倣・支援するAI | 現在実用化されている多くのAI |
| 強いAI | 本当に理解や意識を持つと考えられるAI | 実現可能性は議論中 |

ジョン・サールは、中国語の部屋の思考実験を通じて「知的に見える応答」と「意味理解」は別であると主張した。

## 中国語の部屋

**中国語の部屋**は、ジョン・サールが1980年に提示した思考実験。

中国語を理解しない人が部屋の中にいて、外から中国語の質問を受け取る。部屋の中の人はルールブックに従って記号を操作し、正しい中国語の返答を外へ出す。

外から見ると中国語を理解しているように見えるが、部屋の中の人は意味を理解していない。

| 観点 | 内容 |
|------|------|
| 問題提起 | 記号操作だけで意味理解は成立するのか |
| 関連概念 | syntax（統語論）と semantics（意味論） |
| 重要性 | チューリングテストの限界を考える材料 |

!!! note "試験ポイント"
    中国語の部屋は「記号操作だけでは意味理解とは言えない」という強いAI批判として押さえる。

## シンボルグラウンディング問題

**シンボルグラウンディング問題**とは、記号が現実世界の対象や意味とどのように結びつくのか、という問題。

辞書の中で「りんご」を別の言葉で説明し続けても、実物を見たり触れたり食べたりする経験がなければ、意味の土台が得られないという考え方。

| 要素 | 説明 |
|------|------|
| 記号 | 言葉や記号表現 |
| 知覚・行為 | 見る、触る、動く、食べるなどの経験 |
| 世界 | 現実の対象 |

提唱者はスティーブン・ハーナッド。AIが言葉の意味を扱うためには、記号と世界を結びつける仕組みが必要だとされる。

## 身体性

**身体性**とは、知能が頭の中だけで成立するのではなく、身体を通じた環境との相互作用から生まれるという考え方。

- 知覚、運動、行為が知能の形成に重要
- ロボットが歩く、物をつかむ、障害物を避ける、触って学ぶなどが例
- 記号だけでは扱いにくい知識を補う視点になる

関連人物・用語：

- ロドニー・ブルックス
- エンボディメント（Embodiment）
- サブサンプション・アーキテクチャ

!!! note "試験ポイント"
    身体性は、身体と環境の相互作用を重視する考え方。ブルックスと結びつけて覚える。
