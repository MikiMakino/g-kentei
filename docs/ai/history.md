# AIの歴史

## AIブームの変遷

| 時期 | 中心テーマ | 代表例 | 限界 |
|------|------------|--------|------|
| 第1次AIブーム | 探索・推論・記号処理 | 迷路、パズル、定理証明、ゲーム | 現実世界の複雑さに弱い |
| AIの冬 | 研究停滞 | 期待と成果のギャップ | 計算資源・データ・知識表現の不足 |
| 第2次AIブーム | 知識表現・エキスパートシステム | MYCIN、XCON | 知識獲得のボトルネック |
| 第3次AIブーム | 機械学習・深層学習 | ImageNet、AlphaGo、生成AI | 倫理、説明可能性、ガバナンス |

### 第1次AIブーム（1950〜1960年代）：推論・探索

- コンピュータによる**推論・探索**で知的問題を解こうとした時代
- 1946年：ENIACの開発。汎用電子計算機の発展がAI研究の土台になる
- **チューリングテスト**（1950年）：機械が人間と区別できない応答ができるかを問うテスト
- **ダートマス会議**（1956年）：「人工知能（Artificial Intelligence）」という言葉が初めて使われた
- トイ・プロブレム（おもちゃの問題）は解けたが、現実の複雑な問題には対応できず冬の時代へ

### AIの冬（1960年代後半〜1970年代）

- 期待に対して成果が限定的だった
- 組合せ爆発により計算量が急増した
- 現実世界の知識を扱うことが難しかった
- 計算機性能や利用可能なデータが不足していた

!!! note "試験ポイント"
    第1次AIブームは「探索・推論・記号処理」、その後の停滞は「AIの冬」として整理する。

### 第2次AIブーム（1980〜1990年代）：エキスパートシステム

- 専門家の知識をルールとしてプログラムした**エキスパートシステム**が登場
- 「もし〜ならば〜」という形式（IF-THENルール）で知識を蓄積
- 医療診断・設計支援などに活用
- **知識ベース**、**推論エンジン**、**ユーザーインターフェース**で構成される
- 代表例：MYCIN（医療診断支援）、XCON（コンピュータ構成支援）
- 知識の記述・維持に膨大なコストがかかり限界が露呈 → 再び停滞へ

### 知識獲得のボトルネック

専門家の暗黙知を聞き取り、整理し、ルール化し、システムに登録する作業が大きな負担となる問題。

| 工程 | 難しさ |
|------|--------|
| 専門家への聞き取り | 経験に基づく判断を言語化しにくい |
| 知識整理 | 例外や条件分岐が多く複雑になる |
| ルール化 | IF-THENルールとして表現しきれない知識がある |
| 保守 | 環境変化や新知識に合わせた更新コストが高い |

!!! warning "第2次AIブームの限界"
    エキスパートシステムは特定分野では有効だったが、知識獲得のボトルネックと保守コストが大きな課題だった。

### 第3次AIブーム（2010年代〜）：機械学習・ディープラーニング

- **2012年**：ImageNet画像認識コンテストで **AlexNet（CNN）** が圧勝 → ディープラーニング革命
- ビッグデータとGPUによる計算性能向上が背景
- 画像認識・音声認識・自然言語処理で人間を超える性能を達成
- 2016年：AlphaGoが囲碁でトップ棋士に勝利し、深層学習と強化学習が注目される
- 2017年：Transformerが登場し、自然言語処理や生成AIの重要な基盤となる
- 2022年：ChatGPTの登場により、生成AIの一般利用が急速に広がる

### 第3次AIブームの背景

| 要因 | 内容 |
|------|------|
| データ | インターネットやセンサーにより大量データが利用可能になった |
| 計算資源 | GPUなどにより大規模な学習が現実的になった |
| アルゴリズム | 誤差逆伝播法、CNN、RNN、Transformerなどが発展した |

!!! note "年代の整理"
    第3次AIブームは2000年代以降の機械学習の発展を背景に、2010年代のディープラーニングで本格化したと押さえる。

## 代表的な年表

| 年 | 出来事 | 試験での押さえ方 |
|----|--------|------------------|
| 1946年 | ENIACの開発 | AI研究の土台となる計算機の発展 |
| 1950年 | チューリングテスト | 機械が知的に見えるかを対話で評価 |
| 1956年 | ダートマス会議 | AI研究の出発点、「人工知能」という語 |
| 1960年代後半〜 | AIの冬 | 期待外れ、計算資源不足、組合せ爆発 |
| 1980年代 | 第2次AIブーム | エキスパートシステム、知識の時代 |
| 1990年前後 | 再停滞 | 知識獲得のボトルネック |
| 1990年 | 世界初のWebページ | World Wide Web の仕組みが実装され、最初のWebサーバーとブラウザが作られた |
| 2012年 | ImageNetでAlexNetが高性能 | 深層学習が注目される転機 |
| 2016年 | AlphaGo | 深層学習・強化学習の象徴 |
| 2017年 | Transformer | LLM・生成AIの基盤 |
| 2022年 | ChatGPT | 生成AIの一般利用が拡大 |

!!! note "世界初のWebページ"
    G検定公式テキストでは「1990年 世界初のWebページ」と整理される。ティム・バーナーズ＝リーがCERNで World Wide Web を実装し、最初のWebサーバーとブラウザが作られた時期として押さえる。

## シンボリックAI vs サブシンボリックAI

| 種類 | 特徴 | 例 |
|------|------|----|
| シンボリックAI | ルール・論理で知識を表現（人間が記述） | エキスパートシステム |
| サブシンボリックAI | データから統計的にパターンを自動学習 | ニューラルネットワーク |

## 特化型AI vs 汎用AI

| 種類 | 説明 | 現状 |
|------|------|------|
| 特化型AI（Narrow AI） | 特定タスクのみ実行 | 現在実用化されているすべてのAI |
| 汎用AI（AGI） | 人間と同等の汎用的知能 | 未実現 |
| 超知能（Super Intelligence） | 人間をはるかに超える知能 | 仮説的概念 |

## シンギュラリティ

**技術的特異点（シンギュラリティ）**：AIが人間の知能を超え、急速に自己改善を繰り返すことで予測不能な変化が起きるとされる時点。レイ・カーツワイルが **2045年** と予測。

!!! warning "現在の重要論点"
    生成AIの普及により、バイアス、公平性、説明可能性、著作権、個人情報、セキュリティ、AIガバナンス、人間とAIの役割分担が重要になっている。
