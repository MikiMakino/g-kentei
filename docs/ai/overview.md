# AIとは

## 人工知能の定義

**人工知能（Artificial Intelligence, AI）** とは、人間の知的活動をコンピュータで再現する技術の総称。

明確な定義は存在せず、研究者によって異なる。

## AI・機械学習・ディープラーニングの関係

```
AI（人工知能）
└── 機械学習（Machine Learning）
    └── ディープラーニング（Deep Learning）
```

- **AI** ：人間の知能を模倣する技術全般
- **機械学習** ：データからルールを自動学習する手法
- **ディープラーニング** ：多層ニューラルネットワークを使った機械学習

## AIの種類

### 特化型AI（Narrow AI）
特定のタスクのみ実行できるAI。現在実用化されているAIのほとんど。

例：画像認識、音声認識、囲碁AI（AlphaGo）

### 汎用AI（AGI: Artificial General Intelligence）
人間と同等の知的能力を持つAI。現時点では実現していない。

## AIブームの歴史

| 時期 | 内容 |
|------|------|
| 第1次（1950〜60年代） | 推論・探索による問題解解 |
| 第2次（1980〜90年代） | エキスパートシステム |
| 第3次（2010年代〜） | ディープラーニングによるブレークスルー |

!!! note "ポイント"
    第3次AIブームのきっかけは2012年の **ImageNet競技会** でのディープラーニングの圧勝。
