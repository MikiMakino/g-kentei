# CNN・RNN

## CNN（畳み込みニューラルネットワーク）

画像認識に特化したネットワーク。**局所的な特徴** を自動で抽出する。

### 構成要素

#### 畳み込み層（Convolutional Layer）

- **フィルタ（カーネル）** をスライドさせて特徴マップを生成
- **エッジ・テクスチャ・形状** などを階層的に検出
- パラメータ共有により全結合層より効率的

#### プーリング層（Pooling Layer）

- 特徴マップをダウンサンプリング（サイズ縮小）
- **最大プーリング（Max Pooling）** が主流
- 位置変化に対するロバスト性を高める

#### 全結合層（Fully Connected Layer）

- 最終的な分類・回帰を行う
- 畳み込み層で抽出した特徴を統合

### 代表的なCNNアーキテクチャ

| モデル | 年 | 特徴 |
|--------|-----|------|
| LeNet | 1998 | 初期のCNN、手書き文字認識 |
| AlexNet | 2012 | ImageNet優勝、ReLU・Dropout・GPU使用 |
| VGGNet | 2014 | 3×3の小さいフィルタを深く積み重ね |
| GoogLeNet（Inception） | 2014 | Inceptionモジュール、並列畳み込み |
| ResNet | 2015 | 残差接続（Skip Connection）で超深層化 |
| EfficientNet | 2019 | スケーリング係数で精度と効率を両立 |

!!! note "残差接続（ResNet）"
    入力をそのまま出力に加算するショートカット。勾配消失を防ぎ、100層超のネットワークを実現。

### 転移学習とファインチューニング

- **転移学習**：大規模データで事前学習したモデルを別タスクに流用
- **ファインチューニング**：事前学習済みモデルのパラメータを新タスクで微調整
- 少ないデータでも高精度を達成できる

## RNN（再帰型ニューラルネットワーク）

**時系列・テキスト** など順序のあるデータを扱うネットワーク。

### 基本構造

- 前の時刻の**隠れ状態（Hidden State）** を次の時刻の入力と合わせて処理
- 過去の情報を保持できる

### 問題点

- 長い系列では**勾配消失**が発生し、遠い過去の情報が失われる

## LSTM（Long Short-Term Memory）

RNNの勾配消失問題を解決した改良版。

### ゲート機構

| ゲート | 役割 |
|--------|------|
| 入力ゲート | 新しい情報をどれだけ記憶に加えるか |
| 忘却ゲート | 過去の記憶をどれだけ忘れるか |
| 出力ゲート | 記憶からどれだけ出力するか |

- **セル状態（Cell State）** が長期記憶を保持

## GRU（Gated Recurrent Unit）

- LSTMを簡略化したモデル
- ゲートが2つ（リセット・更新）でLSTMより計算が軽い
- 精度はLSTMと同程度のことが多い

## Seq2Seq（Encoder-Decoder）

```
入力系列 → Encoder（RNN） → コンテキストベクトル → Decoder（RNN） → 出力系列
```

- 機械翻訳・文章要約に使用
- **Attention機構** を加えることで長い系列も対応

## Attention機構

- Decoderが出力を生成する際、Encoderの**どの部分に注目するか** を学習
- 長距離依存を捉えやすい
- Transformerの基礎となる仕組み

## CNN vs RNN の使い分け

| データ | 適したモデル |
|--------|------------|
| 画像 | CNN |
| 時系列・音声 | RNN/LSTM |
| テキスト | Transformer（現在の主流） |
| 動画 | CNN + RNN の組み合わせ |
