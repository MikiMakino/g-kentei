# 最新モデル

## Transformer

2017年の論文「Attention Is All You Need」で提案。**自然言語処理の主流** となったアーキテクチャ。

### 特徴

- RNNを使わず **Self-Attention（自己注意機構）** のみで構成
- **並列処理** が可能で学習が高速
- 長距離の依存関係を効率よく捉えられる

### Self-Attention

文中のすべての単語の関係を同時に計算する。

```
「猫が魚を食べた」
→ 「食べた」は「猫」と「魚」の両方に注意
```

### Encoder-Decoder構造

| 構成 | 役割 | 代表モデル |
|------|------|----------|
| Encoderのみ | 文の意味理解 | BERT |
| Decoderのみ | テキスト生成 | GPT |
| Encoder + Decoder | 翻訳・要約 | T5、BART |

## 大規模言語モデル（LLM）

大量のテキストを事前学習し、文章生成・要約・翻訳・質問応答などに利用される基盤モデル。

| 用語 | 説明 |
|------|------|
| 事前学習 | 大量データで汎用的な言語能力を獲得 |
| ファインチューニング | 特定タスクやドメインに追加学習で適応 |
| プロンプトエンジニアリング | 入力文を工夫して望ましい出力を得る |
| RAG | 外部知識を検索して回答に利用する手法 |

### BERT（2018年, Google）

- **Bidirectional（双方向）** Transformer Encoder
- **事前学習タスク**：
  - Masked LM（穴埋め）
  - Next Sentence Prediction
- 文章分類・固有表現認識・QAで高精度

### GPT シリーズ（OpenAI）

| モデル | 年 | 特徴 |
|--------|-----|------|
| GPT-1 | 2018 | 生成型事前学習の実証 |
| GPT-2 | 2019 | 1.5B パラメータ、テキスト生成の高品質化 |
| GPT-3 | 2020 | 175B パラメータ、few-shot学習 |
| GPT-4 | 2023 | マルチモーダル（テキスト＋画像） |

### ChatGPT・RLHF

- **RLHF（人間フィードバックによる強化学習）** でモデルを人間の意図に合わせる
- InstructGPT → ChatGPT へと発展
- ハルシネーション（もっともらしい誤情報）に注意が必要

### 生成AIのリスク

| リスク | 内容 |
|--------|------|
| ハルシネーション | 事実でない内容を自然に生成する |
| 著作権侵害 | 学習データ・生成物が権利を侵害する可能性 |
| 情報漏えい | 入力した機密情報が外部サービスに送信される |
| 悪用 | フィッシング、偽情報、なりすましに使われる |

## 画像生成 AI

### GAN（敵対的生成ネットワーク）

```
Generator（生成器）← フィードバック → Discriminator（識別器）
```

- GeneratorとDiscriminatorが互いに競い合いながら学習
- **StyleGAN**：高品質な顔画像生成

### VAE（変分オートエンコーダ）

- データを**潜在空間**に圧縮・復元
- 潜在変数を操作することで多様な生成が可能

### 拡散モデル（Diffusion Model）

- ノイズを加えていく過程を逆にたどってデータを生成
- **Stable Diffusion**・**DALL-E 3**・**Midjourney** で採用
- 現在の画像生成の主流

## モデルの軽量化

大規模モデルは高精度だが、計算コスト・メモリ・消費電力が大きい。実運用では軽量化が重要。

| 手法 | 説明 |
|------|------|
| 蒸留（Distillation） | 大きな教師モデルの知識を小さな生徒モデルへ移す |
| 量子化（Quantization） | 重みや計算を低ビット化して高速化・省メモリ化 |
| 枝刈り（Pruning） | 重要度の低い重みやニューロンを削除 |
| LoRA | 一部の低ランク行列だけを追加学習する効率的なファインチューニング |

## 転移学習とファインチューニング

| 用語 | 説明 |
|------|------|
| 転移学習 | 事前学習済みモデルを別タスクに再利用する |
| ファインチューニング | 事前学習済みモデルの一部または全体を追加学習する |
| 凍結 | 既存の重みを更新せず、新しい層だけ学習する |

!!! note "試験ポイント"
    転移学習は、少ないデータでも高性能を得やすく、学習時間を短縮できる。
