# AI倫理

## なぜAI倫理が重要か

AIが社会に普及することで、以下のリスクが生じる：

- 差別・偏見の自動化・拡大
- プライバシーの侵害
- 意思決定の透明性の欠如
- 人間の雇用・権利への影響

## AI倫理の主要原則

JDLAおよび国際機関が提唱する共通原則：

| 原則 | 説明 |
|------|------|
| **公平性（Fairness）** | 人種・性別・属性で差別しない |
| **透明性（Transparency）** | AIの判断根拠を説明できる |
| **説明責任（Accountability）** | AIの結果に責任を持つ |
| **安全性（Safety）** | 人や社会に害を与えない |
| **プライバシー保護** | 個人情報を適切に扱う |
| **人間中心** | 人間の尊厳・自律を尊重 |
| **セキュリティ** | 不正利用・攻撃・情報漏えいを防ぐ |
| **持続可能性** | 環境負荷や社会への長期影響に配慮する |

## バイアス問題

### AIにおけるバイアスの種類

| バイアス | 説明 |
|---------|------|
| **データバイアス** | 訓練データに偏りがある |
| **確証バイアス** | 既存の偏見を反映する |
| **自動化バイアス** | AIの判断を過度に信頼する |

### 具体例

- 採用AIが特定の性別・人種を低評価
- 顔認識AIが特定の肌の色で精度が低い
- 融資判断AIが過去の差別的パターンを再現

## 説明可能なAI（XAI: Explainable AI）

ブラックボックス問題：ディープラーニングは精度は高いが**なぜその判断をしたか分かりにくい**。

### 説明手法

| 手法 | 説明 |
|------|------|
| **LIME** | 局所的な線形近似で予測を説明 |
| **SHAP** | 各特徴量の貢献度を計算 |
| **Grad-CAM** | 画像のどの部分に注目したかを可視化 |

## フェアネス指標

| 指標 | 内容 |
|------|------|
| 個人公平性 | 似た人には似た結果を |
| 集団公平性 | グループ間で結果の分布が均等 |
| 反事実的公平性 | 属性だけ変えた場合に結果が変わらない |

## AIと人間の関係

### 自動化と人間の監督

- **Human-in-the-Loop**：重要な判断には人間の確認を挟む
- 医療・司法・採用などでは特に重要

### AIの権利・責任

- 現時点でAIに法的権利・人格はない
- AIが引き起こした損害の責任は**開発者・運用者**が持つ

## AIガバナンス

AIガバナンスとは、AIを安全・公平・透明に利用するための組織的な管理体制。

| 観点 | 内容 |
|------|------|
| 体制 | 責任者、審査プロセス、相談窓口を決める |
| リスク管理 | 誤判定、差別、情報漏えい、悪用を評価する |
| 監査 | 利用目的、データ、モデル更新履歴、判断ログを記録する |
| 教育 | 利用者にAIの限界、禁止事項、確認手順を周知する |

### 人間の監督

- AIの出力をそのまま最終判断にしない
- 重要な意思決定では人間が確認・修正できるようにする
- 誤りを発見したときの報告・改善ルートを用意する
