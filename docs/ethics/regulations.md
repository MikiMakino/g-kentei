# 法規制

## 日本の法規制・ガイドライン

### 個人情報保護法

- 個人情報の取扱いに関する基本法
- **個人情報**：生存する個人を識別できる情報
- **要配慮個人情報**：人種・信条・病歴など、特に慎重な取扱いが必要
- AIによる個人情報処理にも適用される

### AI戦略・政策

| 文書 | 概要 |
|------|------|
| AI戦略2022 | 国家AIビジョン、人材育成・研究開発・社会実装 |
| 人間中心のAI社会原則（2019年） | 基本理念・AIの設計指針 |
| AI利活用ガイドライン（総務省） | 利用者向けの行動指針10カ条 |

### 不正競争防止法

- **データ不正取得・使用の禁止**
- 秘密として管理された**営業秘密**の保護
- AIを使ったデータ収集・学習にも関係

### 著作権法

- AI学習では、情報解析目的の利用が論点になる
- 生成物が既存著作物と類似し、依拠性がある場合は侵害リスクがある
- 生成AIの利用規約や商用利用可否も確認する

### 特許法

- 発明として保護されるには、自然法則を利用した技術的思想の創作であることが必要
- AIを道具として人間が発明した場合は、人間が発明者となる
- AIそのものは現行法上、原則として発明者にはならない

### 独占禁止法

- AIによる価格最適化や推薦が、競争制限や不当な差別的取扱いにつながる場合に問題となる
- アルゴリズムを使った価格協調、優越的地位の濫用、データ囲い込みに注意

### AI開発・利用契約

| 契約上の論点 | 内容 |
|--------------|------|
| 成果物の権利 | 学習済みモデル、ソースコード、生成物の権利帰属 |
| データ利用権限 | 提供データを学習・再利用してよい範囲 |
| 責任分界 | 精度不足、障害、第三者権利侵害時の責任 |
| 秘密保持 | 入力データ、学習データ、モデル情報の管理 |
| 保守運用 | 再学習、監視、問い合わせ対応の範囲 |

## 欧州のAI規制

### EU AI法（AI Act、2024年施行）

世界初の包括的なAI法規制。リスクに基づく分類：

| リスクレベル | 内容 | 例 |
|------------|------|-----|
| **許容不可能**（禁止） | 社会的スコアリング、無差別な顔認識 | 政府による市民スコアリング |
| **高リスク** | 厳格な要件（透明性・監査） | 採用・融資・医療診断AI |
| **限定リスク** | 透明性の義務 | チャットボット（AIと明示） |
| **最小リスク** | 規制なし | スパムフィルタ、AIゲーム |

### GDPR（一般データ保護規則）

- EU市民の個人データ保護
- **自動的な意思決定への異議申立権**：AIのみによる重要な判断に異議を唱えられる
- 日本の個人情報保護法より厳格

## 著作権とAI

### 学習データと著作権

- 日本：著作権法第30条の4で、**情報解析目的** の複製は原則著作権侵害にならない（非享受利用）
- ただし、著作権者の利益を不当に害する場合は例外

### AI生成物の著作権

| 国 | 方針 |
|----|------|
| 日本 | AI単独生成物には著作権なし。人間の創作的寄与があれば保護対象 |
| 米国 | 人間による創作性が必要。AI生成物は原則著作権なし |

## AIと個人情報・プライバシー

### 個人情報に関する注意点

- **匿名加工情報**：個人を特定できないよう加工したデータ（一定の利用が可能）
- **仮名加工情報**：他の情報と照合することで個人を特定できる可能性がある
- **プロファイリング**：行動データから個人の性質・嗜好を推測する行為

### 顔認識AI

- 公共空間での顔認識は多くの国で規制が議論されている
- EU AI法では一部を禁止

## AIセキュリティ

| 脅威 | 説明 |
|------|------|
| 敵対的サンプル（Adversarial Examples） | 人間には分からない微小な変化でAIを誤認識させる |
| データポイズニング | 訓練データに意図的に偏りや誤りを混入 |
| モデル抽出攻撃 | 問い合わせを繰り返してモデルを再現 |
| プロンプトインジェクション | LLMへの悪意ある指示の埋め込み |
| データ漏えい | 学習データや入力情報が出力・ログから漏れる |
| モデル反転攻撃 | モデル出力から学習データの特徴を推測する |
