# G検定 学習ノート

JDLA（日本ディープラーニング協会）主催の **G検定（ジェネラリスト検定）** 対策ノートです。

!!! info "公式サイト"
    - [日本ディープラーニング協会（JDLA）](https://www.jdla.org/)
    - [G検定 公式ページ](https://www.jdla.org/certificate/general/)

## 試験概要

| 項目 | 内容 |
|------|------|
| 主催 | 一般社団法人 日本ディープラーニング協会（JDLA） |
| 対象 | AIを事業に活用するための知識を持つ人材 |
| 形式 | オンライン（自宅受験）、多肢選択式 |
| 時間 | 120分 |
| 出題数 | 約200問 |

## 出題範囲

| カテゴリ | 主なトピック |
|----------|------------|
| AI概論 | AIの定義、歴史、社会実装 |
| 機械学習 | 教師あり・なし学習、評価指標 |
| ディープラーニング | NN・CNN・RNN・Transformer |
| 数学・統計 | 線形代数、確率・統計 |
| 法律・倫理 | AI倫理原則、法規制 |

## このノートの使い方

1. 各セクションを読んで理解する
2. クイズアプリで理解度を確認する
3. 間違えた問題の解説を読み返す
