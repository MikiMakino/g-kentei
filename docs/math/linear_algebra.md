# 線形代数

## ベクトル

- 大きさと方向を持つ量
- **内積**：2つのベクトルの類似度を測る

```
a · b = |a||b|cosθ
```

- 内積が0 → **直交（無相関）**

## 行列

数値を縦横に並べたもの。

### 行列の演算

- **行列積**：(m×n) × (n×p) = (m×p)、順序を変えると結果が変わる（非可換）
- **転置行列**：行と列を入れ替えた行列（Aᵀ）
- **逆行列**：AB = I となる行列 B（正則行列のみ存在）

### 特殊な行列

| 行列 | 説明 |
|------|------|
| 単位行列 I | 対角成分が1、それ以外0 |
| 対角行列 | 対角成分以外が0 |
| 対称行列 | A = Aᵀ |
| 直交行列 | AᵀA = I |

## 固有値・固有ベクトル

```
Av = λv
```

- **v**：固有ベクトル（変換しても方向が変わらないベクトル）
- **λ**：固有値（スケーリングの係数）
- PCAで主成分を求めるのに使用

## ノルム（Norm）

ベクトルの大きさを測る尺度。

| ノルム | 計算 | 用途 |
|--------|------|------|
| L1ノルム | 成分の絶対値の和 | Lasso正則化 |
| L2ノルム | 成分の二乗和の平方根 | Ridge正則化、ユークリッド距離 |

## 行列分解

### 特異値分解（SVD）

```
A = UΣVᵀ
```

- 任意の行列を分解できる
- 次元削減・推薦システムに利用

### 主成分分析（PCA）との関係

- データの共分散行列を固有値分解
- 固有値の大きい順に主成分を取ることで次元削減

## AIへの応用

| 概念 | AI での使われ方 |
|------|--------------|
| ベクトル | 単語・画像の埋め込み表現（Embedding） |
| 行列積 | ニューラルネットの層間の計算 |
| テンソル | 多次元配列。NN のデータ構造の基本単位 |
| 転置 | Attention のスコア計算 |

!!! note "テンソルとは"
    スカラー（0次元）→ベクトル（1次元）→行列（2次元）→**テンソル（n次元）**。PyTorchやTensorFlowの基本データ構造。
