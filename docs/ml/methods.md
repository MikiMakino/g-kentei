# 代表的な機械学習手法

## 線形モデル

### 線形回帰（Linear Regression）

- 入力と出力の線形関係をモデル化
- **最小二乗法**でパラメータを最適化
- **正則化**：Ridge（L2）、Lasso（L1）

### ロジスティック回帰（Logistic Regression）

- 2値分類に使用
- シグモイド関数で確率（0〜1）を出力
- 名前に「回帰」とあるが**分類**手法

## 決定木・アンサンブル

### 決定木（Decision Tree）

- データをIF-THENのツリー構造で分類・回帰
- **解釈しやすい**が過学習しやすい
- **ジニ不純度**・**情報利得**で分岐を決定

### ランダムフォレスト（Random Forest）

- 複数の決定木をアンサンブル（多数決）
- **バギング**：異なるデータサンプルで複数のモデルを学習
- 過学習に強く汎化性能が高い

### 勾配ブースティング（Gradient Boosting）

- 弱学習器を順次追加し誤差を補正
- **XGBoost**・**LightGBM** が有名
- テーブルデータでは最強クラスの性能

!!! note "バギング vs ブースティング"
    - バギング：並列に学習、分散を低減（Random Forest）
    - ブースティング：直列に学習、バイアスを低減（XGBoost）

## サポートベクターマシン（SVM）

- クラス間のマージン（余白）を最大化する境界を学習
- **カーネルトリック**：非線形データも扱える（RBFカーネルなど）
- 高次元データに強い

## k近傍法（k-NN）

- 新しいデータに最も近い k 個の訓練データを参照し多数決
- 学習不要（怠惰学習）
- データ数が増えると予測が遅くなる

## クラスタリング

### k-meansクラスタリング

1. k個のクラスタ中心をランダムに初期化
2. 各データを最近傍のクラスタに割り当て
3. クラスタ中心を更新
4. 収束するまで2・3を繰り返す

- クラスタ数 k を事前に指定する必要がある

### 階層的クラスタリング

- データを順次統合または分割してツリー（デンドログラム）を構築
- クラスタ数を事後的に決められる

## 次元削減

### 主成分分析（PCA）

- データの分散が最大になる方向（主成分）に射影
- 高次元データの可視化・前処理に利用

### t-SNE

- 高次元データを2〜3次元に可視化
- 局所的な構造を保持
- 可視化専用（新データへの変換には不向き）

## ベイズ学習

### ナイーブベイズ

- ベイズの定理＋特徴量の独立仮定
- テキスト分類（スパムフィルタ等）に多用
- 学習が高速

## モデル選択

| データの特徴 | おすすめ手法 |
|------------|------------|
| テーブルデータ・分類・回帰 | 勾配ブースティング（XGBoost等） |
| 高次元・少データ | SVM |
| 解釈性が重要 | 決定木、線形回帰 |
| 画像 | CNN（ディープラーニング） |
| テキスト | Transformer（ディープラーニング） |
