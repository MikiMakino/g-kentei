# 直前チートシート

G検定の直前確認用チートシートです。画像を開くと拡大表示できるため、タブレットで確認したり、保存してタッチペンで書き込みながら復習したりできます。

!!! note "使い方"
    まず画像で全体像をつかみ、詳しい説明は各章のテキストページで確認する。試験前は「試験ポイント」と年表を中心に見直す。
