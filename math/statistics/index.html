    確率・統計¶

    基本概念¶

    用語 説明
    確率 事象が起こる可能性（0〜1）
    確率変数 確率的に値が決まる変数
    確率分布 確率変数の値と確率の対応
    期待値 確率的な平均値
    分散 平均からのばらつき
    標準偏差 分散の平方根（元のデータと同じ単位）

    確率の基本ルール¶

    • 加法定理：P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
    • 乗法定理：P(A ∩ B) = P(A) × P(B|A)
    • 独立：P(A ∩ B) = P(A) × P(B)

    ベイズの定理¶

    $$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$$

    • 事前確率 P(A)：証拠なしの確率
    • 尤度 P(B|A)：仮定Aのもとで証拠Bが観測される確率
    • 事後確率 P(A|B)：証拠Bを観測した後の確率

    AIへの応用¶

    • スパムフィルタ（ナイーブベイズ）
    • 医療診断の確率更新
    • ベイズ最適化：ハイパーパラメータ探索

    主要な確率分布¶

    分布 タイプ 特徴・用途
    ベルヌーイ分布 離散 2値の試行（コイン投げ）
    二項分布 離散 n回のベルヌーイ試行
    ポアソン分布 離散 単位時間の事象発生回数
    正規分布（ガウス分布） 連続 最も重要。自然界に多い釣り鐘型
    一様分布 連続 すべての値が等確率
    ベータ分布 連続 確率そのものの分布

    正規分布の重要性

    中心極限定理：独立な確率変数の和は、サンプル数が増えると正規分布に近づく。これがなぜ正規分布が重要かの理由。

    最尤推定（MLE）¶

    観測データが得られる確率（尤度）を最大化するパラメータを求める。

    θ* = argmax P(データ | θ)
    • ニューラルネットの学習は基本的に最尤推定
    • 交差エントロピー損失の最小化 = 最尤推定の最大化

    仮説検定¶

    用語 説明
    帰無仮説 H₀ 「差はない」という仮説
    対立仮説 H₁ 「差がある」という仮説
    p値 帰無仮説が正しいときに観測結果が起こる確率
    有意水準 通常 0.05（5%）。p値がこれを下回れば棄却
    第一種過誤 帰無仮説が正しいのに棄却（False Positive）
    第二種過誤 帰無仮説が誤りなのに採択（False Negative）

    情報理論¶

    エントロピー¶

    情報の不確実性を表す指標。

    • 均等な確率分布 → エントロピー最大
    • 1つの事象が確実 → エントロピー = 0

    交差エントロピー¶

    H(p, q) = -Σ p(x) log q(x)
    • 正解分布 p とモデル予測 q のずれを測る
    • 分類タスクの損失関数 として広く使用

    KLダイバージェンス¶

    2つの確率分布の差異を測る指標。VAEの学習に使用。

    相関と回帰¶

    概念 説明
    相関係数 -1〜1。2変数の線形関係の強さ
    偏相関 他変数の影響を除いた相関
    回帰分析 変数間の関係を式で表す

    相関と因果

    相関関係≠因果関係。アイスクリームの売上と溺死者数は相関するが、因果関係はない（気温が交絡因子）。
