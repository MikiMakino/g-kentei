    機械学習の基礎¶

    機械学習とは¶

    データからパターンを自動的に学習し、予測や判断を行う手法。人間がルールを明示的にプログラムしなくてよい。

    学習の種類¶

    教師あり学習（Supervised Learning）¶

    正解ラベル付きデータで学習する。

    タスク 説明 例
    分類（Classification） カテゴリを予測 スパム判定、画像分類
    回帰（Regression） 数値を予測 株価予測、売上予測

    教師なし学習（Unsupervised Learning）¶

    正解ラベルなしでデータの構造を発見する。

    タスク 説明 例
    クラスタリング 似たデータをグループ化 顧客セグメンテーション
    次元削減 データを低次元に圧縮 PCA、t-SNE
    異常検知 外れ値を検出 不正検知

    強化学習（Reinforcement Learning）¶

    エージェントが環境と相互作用しながら報酬を最大化するよう学習する。

    • エージェント：行動する主体
    • 環境：エージェントが作用する対象
    • 報酬：行動の評価
    • 例：囲碁AI（AlphaGo）、ゲームAI

    半教師あり学習¶

    少量のラベルあり＋大量のラベルなしデータを組み合わせる。

    自己教師あり学習¶

    データ自体から疑似的な正解を生成して学習。BERTの事前学習など。

    過学習と汎化¶

    概念 説明
    過学習（Overfitting） 訓練データには高精度だが未知データに弱い状態
    汎化（Generalization） 未知データにも対応できる状態
    未学習（Underfitting） 訓練データにも対応できていない状態

    対策¶

    • 正則化（L1/L2）：モデルの複雑さにペナルティ
    • ドロップアウト：ランダムにニューロンを無効化
    • データ拡張：訓練データを人工的に増やす
    • 早期終了（Early Stopping）：検証誤差が悪化したら学習を止める

    データの分割¶

    全データ
├── 訓練データ（Training）  ← モデルの学習に使用
├── 検証データ（Validation）← ハイパーパラメータ調整
└── テストデータ（Test）    ← 最終的な性能評価

    交差検証（Cross Validation）¶

    データを k 分割し、k回学習・評価を繰り返す（k-fold CV）。データが少ないときに有効。

    評価指標¶

    分類タスク¶

    混同行列（Confusion Matrix）：

                    予測: Positive    予測: Negative
実際: Positive      TP（真陽性）      FN（偽陰性）
実際: Negative      FP（偽陽性）      TN（真陰性）
    指標 計算式 意味
    正解率（Accuracy） (TP+TN)/(全体) 全体の正解割合
    適合率（Precision） TP/(TP+FP) 陽性予測の正確さ
    再現率（Recall） TP/(TP+FN) 実際の陽性の検出率
    F値（F1スコア） 2×P×R/(P+R) 適合率と再現率の調和平均

    回帰タスク¶

    指標 説明
    MAE 誤差の絶対値の平均
    MSE 誤差の二乗の平均
    RMSE MSEの平方根
    決定係数 R² 1に近いほど良い（最大1）

    特徴量エンジニアリング¶

    • 正規化（Min-Max）：0〜1の範囲にスケーリング
    • 標準化（Z-score）：平均0・分散1に変換
    • ワンホットエンコーディング：カテゴリ変数を数値化

    ノーフリーランチ定理

    すべての問題に最適な汎用アルゴリズムは存在しない。問題に応じて適切な手法を選ぶ必要がある。
